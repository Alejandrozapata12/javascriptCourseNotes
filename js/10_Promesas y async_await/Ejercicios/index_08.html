Ejercicio Async/await

Escenario

Tu portfolio AlejoDev necesita cargar la información de un proyecto desde un archivo JSON simulado.

✍️ Tu misión: Crear una función async llamada getProjectInfo que:
1️⃣ Reciba un projectId
2️⃣ Use await para obtener datos
3️⃣ Maneje errores con try/catch
4️⃣ Retorne el proyecto o null si falla

Función Helper (API simulada)

function fetchProjectData(projectId) { return new Promise((resolve, reject) => { setTimeout(() => { const projects = { 'inventrack': { name: 'Inventrack', tech: ['HTML', 'CSS', 'JS'], status: 'completed' }, 'alejo-dev': { name: 'AlejoDev Portfolio', tech: ['JS', 'Vercel'], status: 'in-progress' } }; if (projects[projectId]) { resolve(projects[projectId]); } else { reject(new Error('Proyecto no encontrado')); } }, 2000); }); }
